API workflows are useful when public Facebook video parsing becomes a repeatable job. Manual downloads are enough for one clip; queues need structured logging.

Test links manually at [https://nowatermarkdownloader.com/tools/facebook-video-downloader](https://nowatermarkdownloader.com/tools/facebook-video-downloader), then review [https://nowatermarkdownloader.com/api-docs](https://nowatermarkdownloader.com/api-docs).

## Store structured fields

Track source URL, request ID, requested mode, platform, job owner, timestamp, provider status, media URL, and failure reason.

## Retry policy

Retry temporary network or provider errors. Do not retry private, deleted, group-only, login-only, or unsupported links as if they were temporary failures.
